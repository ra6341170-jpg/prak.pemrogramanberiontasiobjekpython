# Praktikum Pemrograman Berorientasi Objek Python

Repositori ini berisi kumpulan kode program Python yang dibuat selama sesi perkuliahan praktikum Pemrograman Berorientasi Objek (PBO).

## 🛠️ Cara Menjalankan Kode
1. Pastikan Anda sudah menginstal **Python** di komputer Anda.
2. Buka terminal atau command prompt.
3. Jalankan file program dengan perintah standar:
   ```bash
   python nama_folder/nama_file.py
   ```
   *Contoh:* `python per1/variabel.py`

⚠️ **Catatan Penting untuk File Khusus:**
Untuk file yang memiliki karakter kurung seperti `id().py` di folder `per2`, Anda **wajib menggunakan tanda petik** saat menjalankannya di terminal agar tidak terjadi *error*:
```bash
python "per2/id().py"
```
